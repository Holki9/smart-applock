# Smart AppLock (Замок Приложений) 🔒

Современное, быстрое и надежное Android-приложение для защиты личных приложений PIN-кодом, биометрией (отпечаток пальца / Face Unlock) и инновационным контекстным меню лаунчера.

## 🌟 Ключевые возможности

1. **Мгновенная блокировка через контекстное меню Android (главная особенность):**
   - Удерживайте палец на иконке любого приложения на рабочем столе или в меню (Samsung One UI Home, Pixel Launcher, Nova Launcher и др.).
   - Поверх стандартного контекстного меню появляется интерактивная капсула **«🔒 Заблокировать»** (или «🔓 Снять защиту»).
   - Нажатие в один клик переключает защиту без необходимости заходить в приложение блокировщика!

2. **Защита при запуске (Lock Screen):**
   - Мгновенный перехват защищённых приложений через службу `AccessibilityService`.
   - Ввод 4-значного PIN-кода на удобной сенсорной клавиатуре с тактильной виброотдачей.
   - Поддержка биометрии (отпечаток пальца и распознавание лица через `BiometricPrompt`).
   - Кнопка «Назад» безопасно уводит на домашний экран (`HOME`), не пропуская в приложение без пароля.

3. **Гибкие политики повторной блокировки:**
   - **Сразу при выходе:** блокировать каждый раз при переключении или выходе из приложения.
   - **При выключении экрана:** приложение остаётся разблокированным, пока экран телефона не погаснет.
   - **Таймаут:** через 1 минуту или 5 минут после закрытия.

4. **Защита от непредвиденных обстоятельств и легкое удаление:**
   - **Секретный вопрос:** при первоначальной настройке задается секретный вопрос (например, «Любимый город»). В случае забытого PIN-кода на экране блокировки можно нажать «Забыли PIN?» и мгновенно восстановить доступ или изменить пароль.
   - **Безопасное удаление:** системные «Настройки телефона» по умолчанию **не блокируются**, что гарантирует, что пользователь всегда сможет удалить приложение через *Настройки → Приложения → Smart AppLock → Удалить* и никогда не окажется заблокированным на собственном смартфоне.

5. **Быстрая шторка (Quick Settings Tile):**
   - Плитка в шторке быстрых настроек Android: позволяет заблокировать/разблокировать текущее приложение одним свайпом.

6. **Полностью на русском языке:**
   - Красивый интерфейс Material 3 с поддержкой темной и светлой темы.
   - Поиск по списку приложений и фильтры («Все», «Заблокированные», «Системные»).

## 🛠 Архитектура проекта

- **Язык:** Kotlin 2.1.0
- **UI:** Jetpack Compose + Material 3
- **Службы:**
  - `AppLockAccessibilityService`: обнаружение запуска приложений и долгого нажатия на иконки лаунчера.
  - `LauncherOverlayManager`: отрисовка всплывающей кнопки быстрой блокировки на базе `WindowManager`.
  - `AppLockTileService`: плитка быстрых настроек.
  - `ScreenReceiver`: отслеживание выключения экрана для очистки разблокированных сессий.
- **Безопасность:** Хеширование PIN-кода и секретного ответа через SHA-256 с солью.
